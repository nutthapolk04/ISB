ISB POS — คู่มือติดตั้งเครื่อง POS (ISB-POS-Setup)

คู่มือใช้ตัวติดตั้ง ISB-POS-Setup-1.0.0.exe เพื่อ provision เครื่อง POS Windows ให้พร้อมใช้ EDC + เปิด Chrome kiosk อัตโนมัติในครั้งเดียว

สารบัญ
  1. ภาพรวม
  2. สิ่งที่ต้องเตรียม
  3. ขั้นตอนติดตั้ง
  4. ตรวจรับหลังติดตั้ง
  5. ข้อควรระวัง
  6. แก้ปัญหาเบื้องต้น
  7. อภิธานศัพท์

1ภาพรวม

pos-installer/dist/ISB-POS-Setup-1.0.0.exe คือตัวติดตั้ง (NSIS) สำหรับเครื่อง POS Windows — build ล่าสุดเมื่อ 2026-07-24 บนเครื่อง Mac ด้วย makensis ขนาด ~128MB ไม่ต้องใช้อินเทอร์เน็ตตอนติดตั้งเลย (ไม่มีการดาวน์โหลดอะไรอีกต่อไป) ติดตั้งลง C:\ISB และรันซ้ำได้ปลอดภัย (idempotent — รอบใหม่จะปิด paywire ที่ค้างอยู่ก่อนเขียนทับเอง)

รุ่นนี้ตัด RFID bridge (ACR1252 + NSSM) ออกจาก installer แล้ว — สำหรับเครื่อง POS ที่ใช้ EDC อย่างเดียว ถ้าเครื่องไหนยังต้องการ RFID ให้ใช้ rfid-bridge/ ที่ root ของ repo แยกต่างหาก

ตัวติดตั้งมี 3 component (ติ๊กไว้ทั้งหมดโดย default):

Component ทำอะไร
1. EDC USB driver
(whql_Driver2020)		 copy driver ไป C:\ISB\driver\ แล้วรัน DriverInstall.exe ของ vendor แบบ unattended (ไม่มี wizard/popup ให้กด ติดตั้งอัตโนมัติภายใน ~30 วิ)
2. Paywire EDC bridge copy paywire.exe ไป C:\ISB\paywire\, สร้าง shortcut "Paywire Bridge" ใน Startup (all users) + Desktop แล้วเปิดโปรแกรมให้ทันที — เป็น tray app เสิร์ฟ pos.local.bridge.schooney.tech:7331
3. Chrome kiosk auto-start ตั้ง Chrome enterprise policy LocalNetworkAccessAllowedForUrls = campuscard.isb.ac.th (ให้หน้าเว็บต่อ Paywire bridge ได้โดยไม่โดน permission prompt บล็อก) แล้วสร้าง shortcut "ISB POS Kiosk" ใน Startup (all users) ที่เปิด Chrome แบบ --kiosk https://campuscard.isb.ac.th/login ทุกครั้งที่ล็อกอิน และเปิดให้ทันทีหลังติดตั้งเสร็จ

โครงสร้าง C:\ISB หลังติดตั้ง

C:\ISB\
├── driver\               ← ไฟล์ EDC USB driver (whql_Driver2020)
├── paywire\
│   └── paywire.exe       ← Paywire EDC bridge (tray app)
├── README.txt
└── uninstall.exe

ถอนการติดตั้งได้ผ่าน Add/Remove Programs รายการชื่อ "ISB POS Components" (หรือรัน C:\ISB\uninstall.exe โดยตรง) — จะ stop + remove service, ลบ shortcut และลบ C:\ISB ทั้งโฟลเดอร์ แต่ EDC driver จะยังติดตั้งอยู่กับ Windows ตามปกติของ driver

2สิ่งที่ต้องเตรียม

  • เครื่อง POS ที่รัน Windows 10/11 x64
  • สิทธิ์ Administrator บนเครื่องนั้น (จำเป็น — เขียน registry policy ของ Chrome ไม่ได้ถ้าไม่มี)
  • USB drive ที่มีไฟล์ ISB-POS-Setup-1.0.0.exe
  • เครื่อง EDC + สาย USB
  • Google Chrome ติดตั้งไว้แล้วบนเครื่อง (installer หา path ของ Chrome จาก registry — ถ้ายังไม่ได้ติดตั้ง Chrome จะข้าม shortcut ให้พร้อมคำเตือน)
ไม่ต้องใช้อินเทอร์เน็ตระหว่างติดตั้งเลย — ไฟล์ทั้งหมดฝังมาในตัว exe แล้ว

3ขั้นตอนติดตั้ง

  1. Copy ตัวติดตั้งลงเครื่อง POS

    เสียบ USB drive แล้ว copy ISB-POS-Setup-1.0.0.exe ลงเครื่อง (เช่นวางบน Desktop)

  2. รันแบบ Administrator

    คลิกขวาที่ไฟล์ exe → Run as administrator

  3. UAC

    เมื่อ Windows เด้งหน้าต่าง UAC ถามสิทธิ์ ให้กด Yes

  4. หน้า Welcome

    กด Next ผ่านหน้า Welcome ของตัวติดตั้ง

  5. หน้า Components

    ตรวจว่า component ทั้ง 3 ตัวติ๊กครบ (ค่า default ติ๊กไว้ให้แล้ว) → Next → ปล่อยโฟลเดอร์ติดตั้งเป็น C:\ISB → กด Install

  6. รอจนจบ (unattended ทั้งหมด)

    ทุกขั้นตอนเป็น unattended ไม่มี wizard/popup ให้กด — driver ติดตั้งเงียบๆ ~30 วิ, Paywire bridge เปิดขึ้นมาให้เห็นใน system tray, แล้ว Chrome จะเปิดขึ้นมา แสดงหน้า login ของ ISB POS โดยอัตโนมัติ (kiosk mode) เป็นสัญญาณว่าติดตั้งสำเร็จ

  7. Finish

    กลับมาที่หน้าต่างตัวติดตั้ง กด Finish เป็นอันเสร็จ

    ถ้าเปิด Chrome ค้างไว้อยู่ก่อนแล้ว (ตั้งแต่ก่อนติดตั้ง) ต้อง ปิด Chrome ทุกหน้าต่างแล้วเปิดใหม่ 1 ครั้ง — ไม่งั้น Local Network Access policy ที่เพิ่งตั้งจะยังไม่มีผล และ EDC bridge จะต่อไม่ติด

4ตรวจรับหลังติดตั้ง

ทางลัด: รันสคริปต์ check-pos.ps1 ที่ติดตั้งมาให้แล้วที่ C:\ISB\ — เช็ค driver, Paywire bridge, kiosk shortcut, และ Chrome policy และแก้ให้อัตโนมัติเท่าที่ทำได้ ในครั้งเดียว (ลง patch driver, เปิด Paywire ที่ค้าง, สร้าง kiosk shortcut ใหม่, ตั้งค่า Chrome policy) พร้อมสรุปผล OK/FAIL แยกรายการท้ายสุด — ต้อง Run as administrator (ลง Windows patch/เขียน registry ให้), รันซ้ำได้ไม่จำกัด: 
cd C:\ISB
powershell -ExecutionPolicy Bypass -File check-pos.ps1
ด้านล่างคือรายละเอียดแต่ละข้อเผื่อต้องดีบักเองว่าทำไมข้อไหนไม่ผ่าน
  1. มองหา icon ของ paywire ใน system tray (มุมขวาล่างของ Windows) — ต้องรันอยู่
  2. เช็คว่า kiosk shortcut ถูกสร้างไว้จริง: 
    Test-Path "$env:ProgramData\Microsoft\Windows\Start Menu\Programs\Startup\ISB POS Kiosk.lnk"
    ต้องได้ True — ลอง log out แล้ว log in ใหม่ (หรือ restart เครื่อง) ควรเห็น Chrome เปิดหน้า login ของ ISB POS อัตโนมัติ
  3. ปิด Chrome ทุกหน้าต่างแล้วเปิดใหม่ 1 ครั้งก่อน (ให้ Chrome policy ที่ installer ตั้งไว้มีผล) แล้วเปิด https://campuscard.isb.ac.th → หน้า canteen แล้วทดสอบ:
    • EDC: กดชำระเงิน → เลือกจ่ายด้วย EDC — ต้องเห็น pill สีเขียว ● EDC connected
    • กดปุ่ม QR CODE — ยอดเงิน + QR ต้องขึ้นบนจอเครื่อง EDC

5ข้อควรระวัง

  • ต้อง Run as administrator เสมอ — ไม่งั้นเขียน registry policy ของ Chrome ไม่ได้
  • ห้ามลบ/ย้ายโฟลเดอร์ C:\ISB หลังติดตั้ง — shortcut ของ Paywire ชี้ path นี้ตรง ๆ
  • ติดตั้งซ้ำได้ปลอดภัย (idempotent) — รัน exe ซ้ำเพื่อซ่อมเครื่องที่มีปัญหาได้เลย
  • ถอนการติดตั้งจะไม่ถอน EDC driver หรือ Chrome เอง — ทั้งสองยังอยู่บนเครื่องตามปกติ
  • CSP ของเว็บ campuscard.isb.ac.th อนุญาต pos.local.bridge.schooney.tech:7331 แล้ว (แก้เมื่อ 2026-07-16) — เครื่องใหม่ไม่ต้องตั้งค่าฝั่งเว็บเพิ่ม
  • ตัวติดตั้งตั้งค่า Chrome Local Network Access policy (registry HKLM\SOFTWARE\Policies\Google\Chrome\LocalNetworkAccessAllowedForUrls) ให้อัตโนมัติ — เป็นคนละชั้นกับ CSP (Chrome เช็คแยกก่อนอนุญาตเว็บ public ต่อ local network) แต่ ต้องปิด Chrome ทุกหน้าต่างแล้วเปิดใหม่หลังติดตั้งเสมอ ไม่งั้น policy จะยังไม่มีผลและ EDC bridge จะต่อไม่ติด
  • ฟีเจอร์ Local Network Access ของ Chrome ยังค่อนข้างใหม่และเคยเปลี่ยนชื่อ/รูปแบบ policy มาแล้วหลายรอบ — ถ้า chrome://policy ไม่แสดง LocalNetworkAccessAllowedForUrls เป็น OK เลย ให้เช็คเวอร์ชัน Chrome จริงที่ chrome://version แล้วเทียบชื่อ policy ที่ถูกต้องกับเวอร์ชันนั้นก่อนแก้ installer.nsi

6แก้ปัญหาเบื้องต้น

อาการ วิธีแก้
EDC driver ขึ้นเครื่องหมาย ⚠️ สีเหลืองใน Device Manager check-pos.ps1 (หัวข้อ 4 ด้านบน) เรียก fix-edc-driver.ps1 ให้อัตโนมัติอยู่แล้ว — หรือจะรันตัวแก้ driver อย่างเดียวก็ได้ (ต้อง Run as administrator): 
cd C:\ISB
powershell -ExecutionPolicy Bypass -File fix-edc-driver.ps1
เช็ค Windows Service Pack 1 (เฉพาะ Win7) → ลง patch Windows6.1-KB3033929-x64.msu ที่ bundle มาให้แล้ว → rescan hardware ให้อัตโนมัติตาม DriverInstall_Guide.pdf หัวข้อ 4.3 — ถ้ายังไม่หายให้ทำ manual update driver เอง (ดูหัวข้อ 4.5 ใน PDF เดียวกัน)
F12 → Console ขึ้น ERR_BLOCKED_BY_LOCAL_NETWORK_ACCESS_CHECKS Chrome policy ยังไม่มีผล — ปิด Chrome ทุกหน้าต่างแล้วเปิดใหม่ แล้วเช็คที่ chrome://policy ว่า LocalNetworkAccessAllowedForUrls ขึ้น OK พร้อมค่า campuscard.isb.ac.th — ถ้ายังไม่มีให้ตั้งเองด้วย PowerShell (ดู README.md หัวข้อ Chrome Local Network Access policy) แล้วรีสตาร์ท Chrome ใหม่ — ถ้าตั้งแล้วยัง Ignored ให้เช็คว่า Chrome เวอร์ชันนี้เปลี่ยนชื่อ policy ไปหรือยัง
EDC pill ขึ้นแดง (not connected) เช็คว่า paywire รันอยู่ใน system tray — ถ้าไม่อยู่ให้ดับเบิลคลิก Desktop shortcut "Paywire Bridge" เปิดใหม่ แล้วเช็ค error เพิ่มด้วย F12 → Console
เปิดเครื่อง/login แล้ว Chrome ไม่เปิดหน้า login อัตโนมัติ เช็คว่า shortcut มีอยู่จริง: Test-Path "$env:ProgramData\Microsoft\Windows\Start Menu\Programs\Startup\ISB POS Kiosk.lnk" — ถ้าไม่มี (เช่นตอนติดตั้ง Chrome ยังไม่ได้ลงไว้) ให้ติดตั้ง Chrome แล้วรัน ISB-POS-Setup-1.0.0.exe ซ้ำอีกรอบ
อยากติดตั้งซ้ำทั้งชุด รัน ISB-POS-Setup-1.0.0.exe ใหม่ได้เลย (idempotent — จัดการไฟล์เดิมให้เอง)

7อภิธานศัพท์

คำศัพท์ที่ใช้ในระบบติดตั้งเครื่อง POS และความหมายโดยย่อ
ศัพท์ ความหมาย
Installer (NSIS)ตัวติดตั้ง Windows ที่สร้างด้วย NSIS (Nullsoft Scriptable Install System) — build จาก installer.nsi ด้วย makensis ได้ไฟล์ .exe เดียว
Componentหน่วยติดตั้งที่เลือกติ๊กได้ในหน้า Components ของตัวติดตั้ง (ชุดนี้มี 3 ตัว: driver, Paywire, Chrome kiosk auto-start)
Tray appโปรแกรมที่รันเป็น icon ใน system tray (มุมขวาล่าง) — paywire.exe เป็นแบบนี้
Kiosk modeโหมดของ Chrome (flag --kiosk) ที่เปิดเต็มจอ ไม่มี address bar/แถบ tab ให้กด ใช้สำหรับหน้าจอ POS ที่ต้องล็อกให้ใช้ได้แค่หน้าเดียว
UAC / Run as administratorกลไกขอสิทธิ์ผู้ดูแลระบบของ Windows — ตัวติดตั้งนี้ต้องได้สิทธิ์นี้เสมอ (RequestExecutionLevel admin)
App Paths (registry)รายการ registry ที่ Windows ใช้เก็บ path จริงของโปรแกรมที่ติดตั้งไว้ (เช่น chrome.exe) — installer อ่านจากตรงนี้แทนการเดา path ของ Program Files ตรงๆ
paywire.exePaywire EDC bridge (tray app, .NET 8) ที่เชื่อมหน้าเว็บ POS กับเครื่อง EDC ผ่าน pos.local.bridge.schooney.tech:7331
Local Network Access (PNA)ฟีเจอร์ของ Chrome ที่เช็คแยกจาก CSP — บล็อกเว็บ public ไม่ให้ต่อ localhost/private network เอง (เช่น Paywire bridge ที่ 127.0.0.1:7331) ต้อง whitelist โดเมนผ่าน registry policy LocalNetworkAccessAllowedForUrls (installer ตั้งให้อัตโนมัติ แต่ต้องปิด-เปิด Chrome ใหม่ถึงจะมีผล) — ฟีเจอร์นี้ยังใหม่และเคยเปลี่ยนชื่อ policy มาแล้ว ถ้าไม่ได้ผลให้เช็คชื่อ policy ที่ถูกต้องสำหรับเวอร์ชัน Chrome ที่ใช้จริง
Idempotentคุณสมบัติรันซ้ำได้ผลเหมือนเดิมโดยไม่พัง — installer นี้รันซ้ำเพื่อซ่อม/อัปเดตเครื่องเดิมได้ปลอดภัย
UninstallerC:\ISB\uninstall.exe (รายการ "ISB POS Components" ใน Add/Remove Programs) ใช้ถอนทุกอย่างยกเว้น EDC driver และ Chrome เอง
EDC driver (whql_Driver2020)USB driver ของ vendor สำหรับเครื่อง EDC — ติดตั้งแบบ unattended และติดอยู่กับ Windows แม้ถอน ISB POS Components แล้ว
